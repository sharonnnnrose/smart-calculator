# 🧮 Smart Calculator

A simple and responsive calculator application developed using HTML, CSS, and JavaScript.

## 🚀 Features

- Addition, subtraction, multiplication and division.
- Clear (AC) and Delete (DEL) functions.
- Real-time display.
- Keyboard support.
- Responsive user interface.
- Error handling for invalid calculations.

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

Smart-Calculator/
- index.html
- style.css
- script.js
- README.md

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
